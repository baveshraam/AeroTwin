   THREE REAL BUGS FOUND AND FIXED in tools/fetch_datasets.py while getting this
   far (all Track A territory):
     a) Silent no-op fetch: the fetch() function pre-created the target directory
        before calling Roboflow's .download(), and the Roboflow SDK detects an
        existing directory and skips extraction entirely — it printed "OK:
        downloaded ..." but wrote zero files. Confirmed by testing a direct
        download into a fresh (non-pre-created) path, which worked immediately.
        Fix: rmtree the target dir right before download() instead of mkdir-ing it.
     b) Wrong data.yaml path after merge: merge_aircraft() wrote `path: .` into the
        unified data.yaml. Ultralytics resolves relative `path:` against its own
        internal datasets_dir setting, not the yaml's own directory or CWD — this
        resolved to the repo root and the very first fine-tune attempt crashed
        instantly with "images not found, missing path
        '...\Tata-Innovent\images\val'". Fix: write an absolute posix path
        (AIRCRAFT_DIR.resolve().as_posix()) instead of a relative one. Also
        hand-fixed the already-generated data.yaml on disk rather than re-running
        the (slow, 1024-image) merge copy.
     c) Box vs. polygon mismatch: aircraft-dent-crack exports polygon labels (49
        fields/line — real segmentation masks) but aircraft_skin_defects exports
        plain bounding boxes (5 fields/line). merge_aircraft() previously copied
        label lines through verbatim after only remapping the class index, so the
        merged set would have been a silent mix of polygons and boxes fed to a
        SEGMENTATION model (yolov8s-seg) — Ultralytics would likely either error
        or silently degrade to box-only supervision for those images. Added
        _seg_line(): a box line (cls cx cy w h) is converted to its 4 rectangular
        corners as a degenerate polygon; an already-polygon line passes through
        unchanged. Verified via tools/validate_dataset.py on the real merged set
        afterward: boxes=0, polygons=7722(train)+434(val)+478(test) — every label
        is now a polygon, none silently box-only.
     Extended fetch_datasets.py's own `--selfcheck` self-check to prove the
     box->polygon conversion deterministically (asserts a synthetic 5-field box
     label comes out as a 9-field polygon after merge) — still green.
